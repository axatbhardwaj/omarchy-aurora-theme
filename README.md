# Omarchy Elysian Theme

A desktop theme that translates the mythical serenity of an Elysian forest where ancient, vibrant life glows in golden-green light into a high-contrast, productive workspace.

![Screenshot](screenshot.png)

## Installation

Install this theme by running:

```bash
omarchy-theme-install https://github.com/axatbhardwaj/omarchy-elysian-theme
```

## Balanced Glass

Balanced Glass adds frosted blur, very light inactive dimming, and a luminous active border for a calm, focused workspace. The fully opaque protected set is Steam; specific video, screen-share, and image-tool classes Omarchy excludes by name (zoom, vlc, mpv, kdenlive, OBS, Pinta, imv, NautilusPreviewer); the YouTube and Zoom web app windows; RetroArch; qemu; picture-in-picture overlays; and the webcam overlay. Game-streaming clients (GeForce NOW and Moonlight) remain at normal opacity but are undimmed. Chromium- and Firefox-based browsers sit at 0.98/0.94; everything else, including screenshot tools such as satty, is a normal window at 0.96/0.90 with the theme's light inactive dimming.

## Theme Locations

After installation, certain theme files need to be manually moved to their respective locations:

### Vencord Theme
Move the Vencord theme file to:
```
~/.config/Vencord/themes/
```

Or if using Vesktop:
```
~/.config/vesktop/themes/
```

### GTK Theme
Move the GTK theme file to:
```
~/.config/gtk-4.0/gtk.css
```

For GTK 3:
```
~/.config/gtk-3.0/gtk.css
```
